# ai_memory (MVP_Tenant_app)
Product name: Clientus (PLATFORM_NAME default, «Работает на Clientus»; systemd clientus-api/web/worker, /srv/clientus). Code entity «Booking» = a client's appointment, not the brand.
Stack: Next.js16/React19/TS + Astryx(@astryxdesign/core 0.6.3, CSS-only, no StyleX compiler) + TanStack Query + Zod + Serwist | FastAPI + SQLAlchemy2 + Alembic + SQLite(WAL) | pywebpush.
Layout: api/ (app/, alembic/, tests/), web/ (src/), tenants/<slug>/business.json, deploy/, scripts/.
Decisions: tenant_id from slug/session only (app/tenancy.py session events + composite FKs); bookings+blocks -> resource_occupancies + 15-min occupancy_cells (PK resource_id,cell) under BEGIN IMMEDIATE; instants = UTC epoch minutes; access token = HMAC(secret,tenant|booking|idem-key), only sha256 stored; owner session cookie path-scoped /api/s/<slug>/owner + CSRF header + Origin/X-Forwarded-Host check; assistants: client = booking-first (LLM extracts service/day/time via VseLLM, free times from schedule, chips open BookingSheet), owner = rule answer worded by LLM; fallback rule-based (services/llm.py, intents.py, assistant.py); outbox notification_jobs with lease (services/push.py, app/worker.py); SW = one source src/sw/sw.ts served at /s/<slug>/sw.js; /api proxy route in web for dev; liquid-gl opt-in NEXT_PUBLIC_LIQUID_GL=1 (black in headless).
Astryx: no shadcn (Astryx has BottomSheet/AlertDialog/etc). ru-RU locale provider added. Accent via explicit --color-accent token.
Run: pnpm db:seed, dev:api, dev:web; tests: pnpm test:api / test:web / test:e2e. Ports 8000/3000 may be busy on this machine (use others).
